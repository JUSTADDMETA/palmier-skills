# palmier-skills

Curated and community skills for [Palmier Pro](https://github.com/palmier-io/palmier-pro), the
AI-native macOS video editor.

## Quickstart

### Install inside Palmier Pro

Go to Settings -> Skills. It will fetch the catalog and allows you to choose and download the skills to `~/.palmier/skills/`.
